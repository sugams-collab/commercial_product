Task Manager — React + FastAPI + Tauri/Electron

This repository is a minimal production-like Task Manager used to evaluate desktop wrappers (Tauri vs Electron) with a Python FastAPI backend and a React + Vite frontend.

See subfolders `backend/`, `frontend/`, `electron-app/`, and `tauri-app/` for details and setup instructions.

High level:
- Backend: `backend/` (FastAPI, SQLAlchemy, SQLite)
- Frontend: `frontend/` (React, Vite, TypeScript, TailwindCSS)
- Electron wrapper: `electron-app/` (Node/Electron launcher)
- Tauri: `tauri-app/` (notes + config)

Start with Backend and Frontend setup docs in their subfolders.
